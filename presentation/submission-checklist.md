# Submission checklist

- [ ] Agreement identity, version, and hash are visible.
- [ ] Contribution shares match the team-approved agreement.
- [ ] Repository and pull-request references are public and reviewable.
- [ ] The visible check name is exactly `evidence-check`.
- [ ] Valid examples are merged into `main`.
- [ ] The unmerged example remains open.
- [ ] The wrong-branch example is merged only into `staging`.
- [ ] Single-operator scope is disclosed.
- [ ] No historical fixture is presented as current evidence.
- [ ] No KeeperHub or financial operation occurs without its separate gate.
- [ ] Final walkthrough link is replaced only after a real recording exists.
